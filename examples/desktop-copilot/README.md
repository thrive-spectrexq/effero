# Desktop Copilot Example

This example demonstrates how to configure and run Effero as a local desktop copilot capable of interacting with the system using `computer_use` skills.

## Setup

1. Install dependencies:
   ```bash
   pip install -e "../../.[llm]"
   ```

2. Set your API key:
   ```bash
   export OPENAI_API_KEY="your-key-here"
   ```

3. Run the demo:
   ```bash
   python main.py
   ```
